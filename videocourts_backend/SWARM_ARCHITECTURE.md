## 🏗️ System Architecture

### 1. Core Kernel (`__main__.py`, `core.py`, `controller.py`)
-   **Entry Point:** `python __main__.py` initializes the swarm.
-   **Controller:** Manages agent lifecycle (start/stop/restart).
-   **Database:** `database.py` handles state persistence (SQLite/Postgres).

### 2. Communication Layer (`api.py`, `qr_server.py`, `redis_cache.py`)
-   **QR Server:** Generates handshake codes for mobile Termux integration.
-   **Redis Cache:** High-speed shared memory between agents.
-   **API:** Exposes agent endpoints to the frontend.

### 3. Agent Backend (`backend__agents__*.py`)
-   Each planetary agent has a dedicated backend module.
-   Handles specific logic (e.g., `Mars` handles security scans, `Neptune` handles LLM calls).

### 4. Utilities (`utils.py`, `crypto.py`, `logging.py`)
-   Shared libraries for encryption, logging, and data formatting.

## 🚀 Quick Start (True Mode)

```bash
# 1. Install Dependencies
pip install -r requirements.txt

# 2. Initialize Redis (Required for Swarm Comms)
redis-server --daemonize yes

# 3. Launch the Swarm
python __main__.py --mode=swarm --agents=all

# 4. Verify Status
curl http://localhost:8000/api/swarm/status
```
